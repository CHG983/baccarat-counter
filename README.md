## 目前狀態：Google 登入閘門（示範模式）

未登入時只顯示登入頁，所有算牌與對子功能都被遮蔽且無法操作；登入後才進入主介面，頁首顯示登入者名稱／頭像與登出按鈕，登入狀態保留 30 天。

| 項目 | 目前狀況 |
|---|---|
| 登入頁與閘門 | ✅ 實際運作 |
| 登入狀態保存（重新整理維持） | ✅ 實際運作 |
| 登出、跨分頁同步 | ✅ 實際運作 |
| 連線 Google / 送出資料 | ❌ 否 |
| ID token 簽章驗證 | ❌ 否（`localStorage` 可被偽造） |

登入頁上有 **「啟用真實簽章驗證所需設定」** 檢查表，即時顯示還缺哪幾個值。

## 啟用真實簽章驗證

需要兩個值：

1. **Google OAuth 2.0 用戶端 ID** → 前端 `AUTH_CFG.googleClientId` + 後端 `GOOGLE_CLIENT_ID`
2. **後端驗簽服務網址** → 前端 `AUTH_CFG.backendUrl`

完整步驟（Google Cloud Console 設定、後端部署、環境變數、驗證清單、常見錯誤對照）：

**➡️ [SETUP-AUTH.md](SETUP-AUTH.md)**

後端範例程式在 [`backend/`](backend/)，提供 **Node.js/Express** 與 **Python/FastAPI** 兩個行為完全一致的實作，含測試與煙霧測試腳本。

## 功能

**對子為主攻**，單頁單一流程：

1. **對子作戰台** — 一句話判決、6 格 KPI、莊對／閒對注碼卡、觸發門檻進度條
2. **共用設定** — 牌靴副數、抽水、對子賠率、資金、單位注碼、凱利係數與上限（一處改、全頁重算）
3. **發牌記錄** — 快速輸入欄（可貼整靴）＋ 鍵盤快捷（`A`–`K` 直接發牌、`Backspace` 退牌、`Ctrl+Z` 復原、`/` 跳輸入框）
4. **剩餘牌組與對子集中度** — 逐張扣牌、13 點數剩餘量、對子集中度 6 格
5. **牌組偏差與主注優勢**
6. **機率與期望值** — 莊／閒／和＋對子五行同表，對子置頂
7. **凱利注碼與策略** — 五選項同表、同一組資金與係數
8. **路單** — 珠盤路、大路、大眼仔、小路、蟑螂路
